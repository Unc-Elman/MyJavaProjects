Java Guessing game

A simple interactive console-based guessing game written in java.
The application generates a random number , prompts the player for guesses , provides helpful feedback and tracks the total number of guesses

Features

* Random Generation : It generates a random number between 1 and 10.
* Smart Feedback : Tells the user if their guess is too high or low.
* Attempt tracker : Counts and displays how many times it took you tp find the correct number.
